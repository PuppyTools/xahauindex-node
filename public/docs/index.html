Xahau network · self-hosted

The missing data layer for wallets, explorers, and DEX UIs.

XahauIndex snapshots the current ledger, follows it live, and serves enriched REST + WebSocket APIs for IOUs, URITokens, issuer profiles, DEX candles, and Hooks. No API key. Operators can turn on a per-IP rate limit. Put a reverse proxy in front if you want TLS.

No auth Envelope { data, meta } Native asset XAH OpenAPI 3.1

Conventions

Every successful JSON body uses the same envelope. Identifiers never cram : or + into one path segment.

Response envelope

Lists and details return { data, meta }. meta.ledger_index is the ledger this node had applied when it answered. Paginated lists also include count, page, and per_page.

Token URLs

/v1/tokens/{currency}/{issuer} — e.g. /v1/tokens/USD/rHb9…. Currency is a 3-character code or 40-character hex. Issuer is an r-address.

Pair URLs

/v1/prices/{base}/{counter} with base_issuer / counter_issuer when that side is an IOU. Native XAH has a null issuer and needs no issuer query.

Amounts

IOU values stay decimal strings (including scientific notation from the ledger). XAH drops are converted to XAH for DEX quantities. Icon fields are HTTPS/IPFS links only — this node never caches image bytes.

Errors

Failures are not wrapped in the data envelope.

{
  "error": { "code": "NOT_FOUND", "message": "Token USD/rHb9… not found" }
}
CodeWhen
NOT_FOUNDUnknown route or object
BAD_REQUESTMissing IOU issuer, invalid JSON subscribe, or a 400 from validation
RATE_LIMITEDOptional operator limit (`API_RATE_LIMIT_MAX` / `API_WS_MAX_PER_IP`). HTTP `429` plus `Retry-After`
INTERNALUnexpected server error

Status

Use this for health checks and to know whether balances are still catching the snapshot.

GET /v1/status Open

Indexer health. status is syncing until the snapshot finishes, then live or degraded if lag grows. Docker healthchecks this URL.

URITokens

Xahau native NFTs — not XLS-20. id is the 64-character hex URITokenID.

GET /v1/uritokens Open
ParamDescription
issuer / ownerqueryr-address filters
burnedqueryDefault false
for_salequeryOnly tokens with an active sell offer
sortquerymint_ledger · last_updated

icon_url is a link only. metadata is fetched HTTPS JSON when the URI is a document URL. If the URI is packed on-chain data (not a URL), metadata is a decoded object with source: "onchain" — Evernode leases include lease_index and lease_amount. uri_kind is https, ipfs, image, onchain, or empty.

GET /v1/uritokens/{id}

Includes remarks and the transfer tape. id must be 64 hex characters.

Issuers

AccountRoot domain, TOML verification, blackhole flag, and issuer-side remarks. TOML is fetched off the ledger path and re-checked about every 1000 ledgers.

Profile plus issued tokens, Hook state, and remarks. domain_verified is true only when /.well-known/xahau.toml lists this r-address under [[ACCOUNTS]] or [[CURRENCIES]].

Prices & trades

Executed DEX offers become trades and UTC calendar candles. History exists from meta.history_start_ledger — snapshot-only nodes start at live-from, not genesis, unless backfill is enabled.

GET /v1/prices/{base}/{counter}
ParamDescription
base / counterpathCurrency codes. XAH is native
base_issuerqueryRequired when base is an IOU
counter_issuerqueryRequired when counter is an IOU
periodquery1h · 24h · 7d (default 24h)
from / toqueryUnix seconds; from inclusive, to exclusive
from_ledger / to_ledgerqueryInclusive ledger range
limitquery1–500, default 100

Example: /v1/prices/USD/XAH?base_issuer=rHb9…&period=1h&from=1717200000

GET /v1/trades/{base}/{counter}

Raw tape for the same pair. Same issuer and range params, plus page / per_page.

Hooks

Accounts that currently own a Hook ledger object. Each slot includes the install fields plus the shared HookDefinition (code size, default HookOn, namespace, parameters, fees). HookOn bitmasks become triggers. WASM is not stored. Empty slots are dropped.

GET /v1/hooks Open
ParamDescription
hook_hashqueryOnly accounts that currently install this hash
GET /v1/hooks/definitions Open

Shared HookDefinition catalog. Sorted by how many accounts currently point at the hash.

GET /v1/hooks/definitions/{hook_hash}

404 if that hash is not indexed. code_size is WASM bytes; the bytecode itself is not stored.

GET /v1/hooks/{account}

404 if that account has no indexed Hooks.

WebSocket

One connection, multiple streams. The API listens on the same port — no separate WS host.

WS /v1/subscribe

Send JSON commands. Streams: tokens, uritokens, prices, hooks.

{
  "command": "subscribe",
  "streams": ["tokens", "prices"]
}

Ack: { "type": "subscribed", "streams": ["tokens", "prices"] }. Events look like:

{
  "stream": "tokens",
  "event": "update",
  "ledger_index": 26272654,
  "data": { "currency": "USD", "issuer": "rHb9…" }
}

unsubscribe uses the same shape. Unknown commands and invalid JSON return the standard error object. When the operator cap is on, extra sockets from the same IP are rejected with RATE_LIMITED.
